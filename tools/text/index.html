브라우저 안에서 처리

붙여넣은 텍스트는 서버로 보내거나 저장하지 않습니다. 페이지를 닫으면 입력 내용도 사라집니다.

02

한 줄에 한 항목

정리와 목록 비교는 줄 단위로 처리합니다. CSV 파일의 열 구조나 따옴표 규칙은 해석하지 않습니다.

03

입력 크기 제한
