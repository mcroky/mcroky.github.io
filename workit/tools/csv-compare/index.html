엑셀·CSV 파일 비교·대사

두 표의 변경 행을 찾거나 이름·금액을 기준으로 대사하세요.

STEP 01

비교할 CSV·엑셀 파일 선택

CSV와 XLSX를 섞어서 비교할 수 있습니다. 엑셀은 시트를 하나씩 선택하고, 같은 행을 찾을 고유한 키 열을 고르세요.

기준 파일파일을 선택해 주세요
표
선택한 파일 없음CSV 또는 XLSX 파일
비교 파일파일을 선택해 주세요
표
선택한 파일 없음CSV 또는 XLSX 파일

파일은 브라우저 안에서만 읽습니다. 파일당 5 MB · 최대 5만 행 · 200열. XLSX 수식은 저장된 결과값을 읽고 서식은 비교하지 않습니다.

STEP 02

변경 내용 확인

키가 같으면 양쪽에서 열 이름이 같은 값만 비교합니다. 열 순서는 달라도 됩니다.

STEP 03

비교 결과

CSV 또는 엑셀 파일 두 개를 선택하고 비교하면 결과가 여기에 표시됩니다.

사용 전 알아두세요

01

파일은 브라우저에서 처리

원본 파일과 결과는 서버로 보내거나 저장하지 않습니다. 결과를 내려받으면 기기에 파일이 남습니다.

02

결과 확인

행·셀 비교는 고유 키가 필요합니다. 자동 대사는 같은 이름·금액을 일치로 표시하며 비슷한 이름은 직접 확인할 후보로 둡니다.

03

지원 형식과 크기

CSV(UTF-8·CP949)와 XLSX를 지원합니다. 엑셀 시트를 하나씩 선택하며 수식은 저장된 결과값만 읽습니다. 파일당 5 MB, 비교는 5만 행·대사는 5,000행까지입니다.
