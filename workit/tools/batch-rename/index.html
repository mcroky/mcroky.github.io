FILE TOOLS / 06

파일명 일괄 변경

여러 파일의 이름을 규칙에 맞게 바꾸고 ZIP으로 한 번에 받으세요.

01 / FILES

파일 선택

원본 파일은 바뀌지 않습니다. 새 이름을 적용한 복사본을 ZIP으로 만듭니다.

최대 100개 · 합계 50 MB
02 / RULES

이름 변경 규칙

확장자는 유지하고 파일 이름에만 규칙을 적용합니다.

03 / PREVIEW

변경 결과 미리보기

파일을 선택하면 새 이름을 여기에 미리 보여줍니다.

사용 전 알아두세요

01

원본 유지

브라우저는 PC 파일 이름을 직접 바꿀 수 없습니다. 새 이름의 복사본을 ZIP으로 내려받아 필요한 위치에 풀어 주세요.

02

이름 충돌 확인

미리보기에서 중복 이름이나 Windows에서 쓸 수 없는 문자가 발견되면 ZIP을 만들지 않습니다.

03

브라우저 안에서 처리

파일은 서버로 전송되지 않습니다. 최대 100개, 합계 50 MB까지 처리하며 큰 파일은 브라우저 메모리를 많이 사용할 수 있습니다.
