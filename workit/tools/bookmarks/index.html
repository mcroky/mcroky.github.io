    브라우저 즐겨찾기

    폴더째 가져오기

    이 브라우저에서 처리

    Chrome·Edge 등의 즐겨찾기 관리자에서 HTML 파일로 내보내기를 선택한 뒤, 그 파일을 아래에서 열어 주세요. 일반 웹페이지에서는 브라우저에 저장된 즐겨찾기를 직접 읽을 수 없습니다.

    기존 즐겨찾기는 유지하고 폴더 구조를 합칩니다. 같은 폴더의 중복 주소는 건너뜁니다. 파일은 서버로 전송되지 않으며 최대 5 MB까지 읽습니다.

    사이트 추가

    주소에 https://가 없으면 자동으로 붙입니다.

    사용 전 알아두세요

    01

    이 브라우저에 저장

    사이트 이름과 주소는 현재 브라우저 저장소에 남습니다. 서버로 보내거나 다른 기기와 동기화하지 않습니다.

    02

    브라우저에서 가져오기

    Chrome·Edge 등에서 즐겨찾기를 HTML로 내보낸 뒤 가져올 수 있습니다. 폴더를 유지하고 같은 폴더의 중복 주소는 제외합니다. http·https 주소만 저장합니다.

    03

    저장 한계

    폴더 최대 200개, 사이트 최대 1,000개입니다. 브라우저의 사이트 데이터를 지우면 즐겨찾기도 사라집니다.
