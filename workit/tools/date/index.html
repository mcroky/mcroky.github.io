날짜·근무일 계산

마감일까지 남은 기간과 주말을 뺀 근무일을 바로 계산하세요.

01 / INPUT

두 날짜 사이 계산

시작일은 제외하고 종료일을 포함해 계산합니다.

휴일·휴가일을 YYYY-MM-DD 형식으로 입력하세요. 줄바꿈이나 쉼표로 구분할 수 있습니다. 주말은 자동 제외됩니다.

입력값은 서버로 전송하거나 저장하지 않습니다.

사용 전 알아두세요

01

계산 범위

1900~2100년 날짜를 지원합니다. 기간 계산은 최대 100년, 근무일 뒤 날짜는 최대 10,000일입니다.

02

휴일은 직접 입력

토요일과 일요일은 자동 제외합니다. 한국 공휴일·대체공휴일은 자동 반영하지 않으므로 필요한 날짜를 직접 입력해 주세요.

03

브라우저에서만 계산

날짜와 제외일은 서버로 보내거나 보관하지 않습니다. 페이지를 닫으면 입력값이 사라집니다.
